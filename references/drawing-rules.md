# 绘图注意事项

本文件维护 wjhtywm fork 的个人绘图约定，按“设计类型 → 分类 → 对象 → 规则”的树状结构组织。新增注意事项时加入对应分支；当前任务有明确要求时，以当前任务为准。

```text
原理图
├── 器件选项
│   ├── 阻容
│   │   └── 无特殊说明时，电阻、电容默认选用 0603 封装。
│   └── 晶振
│       └── 无特殊说明时，默认选用 3225 封装。
├── 网络连接
│   └── 电源网络
│       └── 电源及地必须使用电源网络符号，不得使用普通网络标识替代。
└── 标注样式
    └── 器件名称与位号
        └── 同一原理图中，全部器件名称和位号统一采用相同的字体及字号。

PCB
├── 器件布局
│   ├── 朝向与引脚
│   │   └── 根据目标连接方向选择器件朝向，使需要直接互连的焊盘相向或共线，减少绕行与交叉。
│   ├── 同封装器件
│   │   └── 同封装、同方向的器件成行或成列放置时，须按顶/底边或左/右边对齐。
│   ├── 焊盘与边界对齐
│   │   ├── 相邻且需要直接互连的同网焊盘，按连接方向尽量中心对齐，或按选定的顶/底/左/右边缘对齐。
│   │   └── 相邻器件或功能组需要统一排列时，可按焊盘或封装边缘建立共同基准；不同网络之间的几何对齐不改变电气连接。
│   ├── 成组排列
│   │   └── 同一局部行列中的器件按统一基准、等间距排列，以实际封装边界检查间隔。
│   ├── 关联器件
│   │   └── 共同构成功能或关键节点的器件就近成组放置，使关键连接和环路尽量短。
│   └── 丝印
│       └── 器件丝印尽量不要重叠。
└── 布线与覆铜
    ├── 布线顺序与地铜
    │   ├── 先完成走线，再进行最终铺铜与重建；修改走线后重新铺铜并复查连通。
    │   └── 无特殊需求时，除负片层外，每个铜层都铺 GND 铜；负片层按其平面定义处理。
    ├── 分层与主走向
    │   ├── 顶层、底层在同一局部区域内采用统一主走向：水平或垂直；连接焊盘、过孔的短接入段除外。
    │   └── 中间层尽量整层保持同一主走向；器件密集导致过孔无法水平或垂直对齐时，允许必要的局部绕行。
    ├── 转角与分支
    │   ├── 不使用 90° 转角；方向转换采用“横—短斜—竖”或“竖—短斜—横”，不走长距离 45° 斜线。
    │   └── 必要时允许 T 型分支，但分支连接处必须添加滴泪，并检查实际铜形与间距。
    ├── 过孔与焊盘
    │   └── 过孔靠近焊盘时，与焊盘中心水平或垂直对齐，从焊盘中心以单段直线连接过孔，不走折线。
    ├── 焊盘进出线
    │   └── 不以擦过焊盘边角或局部搭接边角的方式连接；按实际铜边界对齐，或在焊盘外转为短 45° 段平顺接入。
    └── GND 与大电流路径
        └── 使用铺铜与过孔连接；仅小电流旁路或局部无法铺铜时，才考虑从铺铜引出走线，大电流区域必须铺铜。
```

## 原理图规则执行说明

### 器件选项

- 0603 指英制封装尺寸，约 1.6 mm × 0.8 mm；3225 指公制封装尺寸，约 3.2 mm × 2.5 mm。
- 先满足电气参数与器件适配要求，再应用默认封装。没有适配型号时说明原因，选用满足要求的兼容型号与封装，不将不匹配的器件强制改为默认封装。
- 按库中实际封装和引脚映射核对选型。3225 不表示固定焊盘数，晶振的两焊盘、四焊盘及引脚定义须与实际器件一致。

### 电源网络

- 使用 [`SCH_PrimitiveComponent.createNetFlag`](classes/SCH_PrimitiveComponent.md)：电源选择 `'Power'`，普通地选择 `'Ground'`；模拟地或保护地按设计需要选择相应类型。
- 仅设置导线的网络名、添加普通网络标签，或使用 `createNetPort` 信号端口，都不能代替电源网络符号。电源网名应通过电源网络符号显示，避免再放置普通网络标签作为电源标识。
- 确认创建成功，并将符号的实际连接点接到对应导线或引脚，保持网名一致；通过网表核对电气连接。创建失败时不得静默退回普通网络标识。

### 器件名称与位号

- 通过 [`SCH_PrimitiveAttribute`](classes/SCH_PrimitiveAttribute.md) 读取器件的显示属性，确认名称和位号对应的属性键，再将同一原理图内全部器件名称与位号的 `fontName` 和 `fontSize` 分别统一。
- 优先沿用当前原理图或项目已经确定的统一字体及字号；未指定时，可采用项目的统一值，不将某张图采用的字体或字号作为全局固定规则。新图无指定字体时，名称与位号的 `fontName` 可都使用 `null` 跟随默认字体，同时保持字号一致，并检查显示结果。`null` 本身不是固定字体名。
- 字体和字号须在同一原理图的全部器件名称与位号之间保持一致；粗体、斜体等其他样式按项目要求设置。

## PCB 规则执行说明

### 器件与焊盘对齐

- 先确定局部器件组的连接方向，再选择各器件朝向。连接器、电阻、电容等可分别旋转或调换排列位置，使需要直接连接的焊盘相向或共线；旋转角度由实际引脚网络和连接方向决定。
- 同封装、同方向的器件成行或成列排列时，依据实际封装轮廓或对应焊盘的边缘，保持顶/底或左/右对齐；不能只看器件原点坐标相同就认定已对齐。
- 对布局上相邻且需要直接互连的同网焊盘，优先在布局阶段调整位置和方向，使焊盘中心沿预期连线方向对齐。左右放置时，优先让焊盘中心的 Y 坐标一致；上下放置时，优先让 X 坐标一致。不能仅因多个器件共网就要求它们全部集中放置。
- 根据连接需求选择中心对齐或边缘对齐。焊盘尺寸不同、方向不同或受布局约束时，可按选定边缘对齐。例如，左右排列的器件可使指定焊盘顶边或底边对齐，上下排列时可按左边或右边对齐，以便直接、少弯折地连接。
- 指定焊盘顶/底/左/右对齐时，使用旋转后的实际铜焊盘边界建立统一基准，不用器件中心或封装原点代替。相邻器件即使属于不同网络，也可按焊盘或封装边缘作几何对齐；保留各自引脚编号与网络映射。
- 对齐调整仍需满足实际焊盘间距和电气布局要求，例如去耦电容靠近对应电源脚、晶振靠近时钟脚；对齐不能代替间距与电气检查。

### 成组排列与关联器件

- 同一局部行列中的器件，在满足电气与机械要求后，按统一基准水平或垂直等间距排列。以实际封装外缘的净间隔检查分布；尺寸不同的器件不能只用原点等距来判断间隔一致。
- 共同构成某个功能或关键节点的器件应就近组织，例如同一信号调理节点的电阻与电容。优先缩短共有节点的连接与敏感环路，避免为了排列整齐把关联器件拉远。
- 移动或旋转后重新读取实际焊盘几何，核对引脚编号、网名、焊盘朝向、对齐边界、器件间距、丝印及关键连接路径，再判断布局是否满足要求。

### 丝印

- 布局和旋转器件后，检查位号、名称及封装丝印，调整文字位置、方向和必要的字号，尽量消除丝印之间的重叠，并避免覆盖焊盘和落到板外。
- 通过 PCB API 读取和调整实际丝印；PCB 的字号按板上可读性设置，不直接套用原理图的字号。

### 布线顺序与地铜

- 先完成信号走线及必要的局部电源旁路，再进行最终电源覆铜、各层地铜与重建。可提前规划铜区通道，但不得把预先生成的铜面当作布线完成；走线改动后必须重新重建受影响的铜面。
- 无特殊需求时，除负片层外，每个铜层均铺 GND 铜，并以合理的接地过孔连接各层地铜；内层为正片时同样适用。负片层按实际平面定义处理，不机械叠加正片地铜。项目已明确的专用电源层、隔离区域等特殊需求以该项目要求为准。
- 检查实际填充、孤岛、细颈、回流与跨层连通；所有信号、电源和地的连通检查应在最终重建后完成，不能仅检查覆铜边界。

### 分层与主走向

- 顶层、底层在同一局部布线区域内选定统一主走向，主干采用水平段或垂直段，避免同一区域内交替使用两种长距离走向。区域划分应依据器件组和连接需求，不能把每条走线各自划成一个区域规避规则。
- 顶层、底层为接入焊盘或过孔，可以使用必要的短垂直于主走向的段；改变方向仍须通过短 45° 过渡，形成“竖—短斜—横”或“横—短斜—竖”，不得直接形成 90° 转角。
- 中间层尽量整层保持统一主走向。器件密集导致换层过孔无法水平或垂直对齐时，允许必要的局部绕行，并保持短 45° 过渡；不能将局部限制扩大为整层随意改变走向。
- 分配层别、过孔和逃线时同步考虑主走向、回流和已有的布局约束，完成后按实际几何检查，不能只依赖自动布线参数。

### 转角与分支

- 不使用两段互相垂直的走线在焊盘外直接形成 90° 转角。完整接入同一焊盘中心的独立引出线，以焊盘外实际铜形判断，不为消除焊盘内部的方向变化而人为绕线。不用一条长距离 45° 斜线直接连接斜对角焊盘；主要距离由水平、垂直段承担，短 45° 段仅用于方向过渡。
- 必要时允许 T 型分支，但每个 T 型连接处必须添加滴泪，使分支平顺并入主干。核对滴泪已实际生成、属于正确网络与铜层、与分支及主干连续，并满足异网间距；只有设置开关或记录计划不算完成。
- 若用受支持的实心填充接口制作滴泪铜形，记录源走线、节点与填充 ID；源走线修改后重新计算和替换，复查实际间距与连通。静态铜形不会自动随走线更新，不将其称为具有自动关联的原生滴泪。
- 自动布线结果也必须遵守上述转角和分支规则。检查共线分段后的完整路径，修正直角、长斜线及缺少滴泪的 T 型节点；不能把正交自动布线的中间结果直接作为成品。

### 过孔与焊盘

- 过孔靠近焊盘时，按实际焊盘中心选择水平或垂直的出线轴，使过孔中心与焊盘中心的 X 或 Y 坐标一致，并从焊盘中心到过孔中心以单段直线直接连接。
- 不在近焊盘过孔连接中加入不必要的拐弯、折线或绕行；不能因网格吸附或机械套用转角规则，把原本能够中心直连的连接改成折线。焊盘旋转时结合其实际方向选择合适的中心出线轴。
- 先调整过孔位置使其与焊盘对齐，同时检查相邻焊盘、过孔、孔径和铜边间距。检查连接线确实起于焊盘中心、终于过孔中心，且中间没有折点；不能仅凭电气连通认定符合本规则。

### 焊盘进出线

- 以旋转后的实际焊盘铜形和走线宽度判断接入，避免走线仅擦过焊盘角点、局部覆盖边角或从边角突出形成突兀的铜角；同网接触或 DRC 通过不能代替接入几何检查。
- 优先沿焊盘中心或适合的平直边完整接入。需要边缘对齐时，比较走线铜边与焊盘铜边，而不是只让线段中心线落在焊盘边缘。
- 偏移接入可选择移动走线，使其铜边与焊盘选定边界对齐；或将主线移出焊盘边角范围，在焊盘外完成短 45° 过渡后平顺接入。转折位置、线宽及转角应避免再次擦到焊盘角点，并保持邻近焊盘和走线的安全间距。
- 上述规则适用于任何器件的焊盘进出线，不固定某个位号、网络、左右方向或具体偏移量。

### GND 与大电流路径

- GND 和大电流路径采用铺铜与过孔连接；换层与地连接处合理放置过孔，不以细长走线代替应有的铜面。
- 仅在小电流旁路，或局部确实无法铺铜且不属于大电流区域时，才考虑从已连接的铜面引出走线。大电流区域必须铺铜，不能以“局部无法铺铜”为由改用走线，应调整布局或铜面。
- 核对覆铜已经实际填充并连通，检查孤岛、铜面收窄与过孔连接；只有覆铜边界或未重建的铜面不算完成连接。

完成对应设计类型的修改后核对这些约定；DRC 通过不能代替封装、电源符号、字体字号、器件与焊盘对齐、丝印、布线顺序、各层地铜、主走向、转角、T 型滴泪、近焊盘过孔中心直连及焊盘进出线检查。
